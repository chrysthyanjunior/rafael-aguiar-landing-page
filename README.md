# 🏠 Rafael Aguiar | Landing Page Imobiliária

Landing page desenvolvida para o corretor de imóveis **Rafael Aguiar**, com o objetivo de fortalecer sua presença digital e oferecer uma forma moderna, simples e profissional de apresentar seus imóveis e serviços.

Este é um **projeto pessoal desenvolvido por Arthur Kean e Chrysthyan Junior**, criado a partir de uma necessidade real e com foco na construção de uma solução web funcional para o mercado imobiliário.

---

## 💻 Sobre o projeto

A **Rafael Aguiar Landing Page** funciona como uma vitrine digital para o corretor, reunindo informações sobre seus serviços, imóveis disponíveis e formas de contato em uma única página.

O desenvolvimento buscou criar uma experiência simples e agradável para o usuário, permitindo que potenciais clientes conheçam os imóveis e entrem em contato com o corretor de maneira rápida.

### 🎯 Objetivos

* Criar uma presença digital profissional para o corretor;
* Apresentar imóveis de maneira organizada e visual;
* Facilitar o contato com potenciais clientes;
* Desenvolver uma interface moderna e intuitiva;
* Garantir uma boa experiência em diferentes dispositivos.

---

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

* **HTML5** — estrutura da página;
* **CSS3** — estilização, layout e responsividade;
* **JavaScript** — interações e funcionalidades.
